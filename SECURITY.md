# Security Policy

## Supported versions

Only the latest release is supported: the newest ArduDebug board package and the newest VS Code extension. Please check whether a problem still occurs there before reporting it.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub instead:

[Report a vulnerability](https://github.com/NikolaiRadke/ArduDebug/security/advisories/new)

Please describe what you found, how to reproduce it and which system and version you used. You will get an answer as soon as possible. Once the problem is fixed, it will be mentioned in the release notes, with credit to you if you like.
