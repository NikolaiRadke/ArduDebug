# ArduDebug

Breakpoint-Debugging für Arduino Uno, Nano, Leonardo und Mega – ohne zusätzliche Hardware.

Sketch öffnen, F5 drücken: ArduDebug kompiliert, lädt hoch und startet den Debugger.
Beim ersten Start wird der ArduDebug-Core automatisch installiert.

https://github.com/NikolaiRadke/ArduDebug
